## Dónde va el 404 en Zola

No es un `.md`, es un **template**. Va acá:

```
templates/404.html
```

Zola lo detecta automáticamente y genera el `404.html` en el build. No tenés que crear ningún archivo de contenido.

## El template `templates/404.html`

```html
{% extends "base.html" %}

{% block title %}Página no encontrada - {{ config.title }}{% endblock title %}

{% block content %}

        <h1 style="font-size: 2em; color: #93c5fd;">🔍 Página no encontrada</h1>
        <p style="font-size: 1.2em; margin-top: 10px;">
            El sitio fue reestructurado. Si venís del sitio anterior, 
            usá el <strong>buscador de arriba</strong> para encontrar lo que buscás.
        </p>
    </div>

    <div class="article-list">
        <h2>📋 Todas las secciones del sitio</h2>

        {% set main_section = get_section(path="_index.md") %}
        {% for sub_path in main_section.subsections %}
            {% set sub = get_section(path=sub_path) %}
            <h3 style="margin-top: 25px; color: #93c5fd;">
                <a href="{{ sub.permalink }}">{{ sub.title }}</a>
            </h3>
            {% for page in sub.pages %}
                <p style="margin: 5px 0 5px 20px;">
                    <a href="{{ page.permalink }}">{{ page.title }}</a>
                </p>
            {% endfor %}
        {% endfor %}
    </div>
{% endblock content %}
```

## ¿Qué hace esto?

- Hereda de `base.html`, así que **ya tiene el buscador Fuse.js arriba**
- Muestra un mensaje amigable de "sitio reestructurado"
- Lista **todas las secciones y sus páginas** automáticamente (no tenés que mantenerlo a mano)
- Si agregás páginas nuevas, el 404 se actualiza solo con el próximo build

## Si tenés subsecciones (secciones dentro de secciones)

El loop de arriba solo baja un nivel. Si tenés subsecciones anidadas (tipo `home/recetas/`), agregá un nivel más:

```html

    {% set sub = get_section(path=sub_path) %}
    <h3><a href="{{ sub.permalink }}">{{ sub.title }}</a></h3>
    {% for page in sub.pages %}
        <p style="margin-left: 20px;"><a href="{{ page.permalink }}">{{ page.title }}</a></p>
    {% endfor %}
    {# subsecciones anidadas #}
    {% for subsub_path in sub.subsections %}
        {% set subsub = get_section(path=subsub_path) %}
        <h4 style="margin-left: 20px;"><a href="{{ subsub.permalink }}">{{ subsub.title }}</a></h4>
        {% for page in subsub.pages %}
            <p style="margin-left: 40px;"><a href="{{ page.permalink }}">{{ page.title }}</a></p>
        {% endfor %}
    {% endfor %}
{% endfor %}
```

## Solución: macro recursivo que baja todos los niveles

Reemplazá tu `templates/404.html` por esto:

```html

{% macro render_section(path) %}
    {% set sec = get_section(path=path) %}
    <h3 style="margin-top: 25px; color: #93c5fd;">
        <a href="{{ sec.permalink }}">{{ sec.title }}</a>
    </h3>
    {% for page in sec.pages %}
        <p style="margin: 4px 0 4px 20px;">
            <a href="{{ page.permalink }}">{{ page.title }}</a>
        </p>
    {% endfor %}
    {% for sub_path in sec.subsections %}
        {{ self::render_section(path=sub_path) }}
    {% endfor %}
{% endmacro render_section %}

<div style="text-align: center; margin-bottom: 40px;">
    <h1 style="font-size: 2em; color: #93c5fd;">🔍 Página no encontrada</h1>
    <p style="font-size: 1.2em; margin-top: 10px;">

    </p>
</div>

    <h2>📋 Todas las páginas del sitio</h2>

    {% set root = get_section(path="_index.md") %}
    {% for sub_path in root.subsections %}
        {{ render_section(path=sub_path) }}
    {% endfor %}
</div>

{% endblock content %}
```

- El **macro `render_section`** se llama a sí mismo recursivamente
